🔐 闭包函数学习案例

1. 什么是闭包？

闭包是指有权访问另一个函数作用域中变量的函数。当一个函数在另一个函数内部定义，并且被返回或传递到外部时，就形成了闭包。

💡 核心特点：函数记住并访问它所在的词法作用域，即使函数在当前词法作用域之外执行。

2. 基础闭包示例 - 计数器

function createCounter() { let count = 0; return { increment: function() { count++; return count; }, decrement: function() { count--; return count; }, getCount: function() { return count; } }; }

3. 闭包实现数据私有化

function createPerson(name) { let age = 18; return { getName: function() { return name; }, getAge: function() { return age; }, birthday: function() { age++; return age; } }; }

4. 循环中的闭包经典问题

for (var i = 0; i < 5; i++) { setTimeout(function() { console.log(i); }, 100); } for (var i = 0; i < 5; i++) { (function(j) { setTimeout(function() { console.log(j); }, 100); })(i); }

5. 函数柯里化（Currying）

function curry(fn) { return function curried(...args) { if (args.length >= fn.length) { return fn.apply(this, args); } else { return function(...moreArgs) { return curried.apply(this, args.concat(moreArgs)); }; } }; } function add(a, b, c) { return a + b + c; } const curriedAdd = curry(add);

const Calculator = (function() { let result = 0; return { add: function(x) { result += x; return this; }, subtract: function(x) { result -= x; return this; }, multiply: function(x) { result *= x; return this; }, divide: function(x) { if (x !== 0) { result /= x; } return this; }, getResult: function() { return result; }, reset: function() { result = 0; return this; } }; })();

📚 闭包的优缺点总结

✅ 优点

  • 数据私有化和封装
  • 保持状态，避免全局变量污染
  • 实现函数柯里化
  • 模块化编程
  • 函数式编程

❌ 缺点

  • 内存占用较大，可能导致内存泄漏
  • 性能影响
  • 代码可读性降低
