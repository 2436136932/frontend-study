# 记账清单 - 详细讲解

## 一、整体架构

这个文件是一个**单页面应用**，没有使用 Vue CLI，而是直接通过 CDN 引入 Vue 3，属于最基础的 HTML + Vue 3 写法。

技术栈：
- **Vue 3**（响应式数据、计算属性、生命周期）
- **Axios**（HTTP 请求）
- **ECharts**（数据可视化图表）
- **原生 CSS**（样式美化）

---

```html
<div id="app">
    <h2>记账清单</h2>
    <!-- 添加区域 -->
    <div class="add-bar">...</div>

    <!-- 总计 -->
    <div class="total">...</div>
```

整个页面分成 4 个区域：

3. **数据表格**：显示消费列表
4. **图表区域**：用 ECharts 展示消费分布

## 四、Vue 3 逻辑详解

### 1. 数据定义（data）

```javascript
data() {
    return {
        items: [],           // 消费列表
        searchName: '',      // 消费名称输入
        searchPrice: '',     // 消费价格输入
        chart: null          // ECharts 实例
    }
}
```

- `items`：存储所有消费记录，每个 item 包含 `id`、`name`、`money`、`create_time`
- `chart`：保存 ECharts 实例，方便后续更新图表

### 2. 计算属性（computed）

```javascript
computed: {
    totalMoney() {
        return this.items.reduce((sum, item) => sum + item.money, 0)
    }
}
```

- 使用 `reduce` 累加所有消费的金额
- **计算属性的特点**：依赖的 `items` 变化时自动重新计算

### 3. 生命周期（created & mounted）

```javascript
created() {
    this.getList()   // 页面创建时获取数据
},

mounted() {
    this.chart = echarts.init(document.getElementById('main'))  // 初始化图表
    this.updateChart()  // 渲染图表
}
```

- `created`：Vue 实例创建完成后调用，适合发请求获取数据
- `mounted`：DOM 挂载完成后调用，适合操作 DOM（如初始化 ECharts）

**为什么不能把图表初始化写在 created 里？**
因为 `created` 时 DOM 还没渲染，找不到 `#main` 元素。

### 4. 获取列表（getList）

```javascript
async getList() {
    const res = await axios.get('https://applet-base-api-t.itheima.net/api/cart', {
        params: { creator: 'admin' }
    })
    
    this.items = res.data.list.map(item => ({
        id: item.goods_id,
        name: item.goods_name,
        money: item.goods_price * item.goods_count,
        create_time: new Date().toLocaleString()
    }))
    
    this.$nextTick(() => {
        this.updateChart()  // 数据更新后刷新图表
    })
}
```

- 使用 `axios.get` 发送 GET 请求
- `params`：URL 查询参数，最终会变成 `?creator=admin`
- `map`：把后端返回的数据格式转换成前端需要的格式
- `this.$nextTick`：等 DOM 更新完成后再更新图表

### 5. 添加消费（add）

```javascript
async add() {
    // 1. 表单验证
    if (!this.searchName.trim() || !this.searchPrice) {
        alert('不能为空')
        return
    }

    // 2. 发送 POST 请求
    const res = await axios.post('https://applet-base-api-t.itheima.net/api/post', {
        goods_name: this.searchName.trim(),
        goods_price: Number(this.searchPrice),
    })

    // 3. 添加到本地列表
    this.items.push({
        id: Date.now(),
        name: res.data.data.goods_name,
        money: res.data.data.goods_price,
        create_time: new Date().toLocaleString()
    })

    // 4. 清空输入框
    this.searchName = ''
    this.searchPrice = ''

    // 5. 更新图表
    this.updateChart()
}
```

**流程解析：**
1. **验证**：名称和价格不能为空
2. **POST 请求**：把数据发送到服务器
3. **本地更新**：把返回的数据添加到 `items` 数组
4. **清空输入**：让用户可以继续添加下一个
5. **更新图表**：同步刷新饼图

**注意**：`Number(this.searchPrice)` 把字符串转成数字，因为输入框的值默认是字符串。

### 6. 删除消费（del）

```javascript
async del(id) {
    this.items = this.items.filter(item => item.id !== id)
    this.updateChart()
}
```

- `filter`：返回一个新数组，排除掉要删除的项
- 然后更新图表

### 7. 更新图表（updateChart）

```javascript
updateChart() {
    // 1. 把 items 转换成 ECharts 需要的数据格式
    const data = this.items.map(item => ({
        value: item.money,   // 扇区大小
        name: item.name       // 扇区名称
    }))

    // 2. 设置图表配置
    this.chart.setOption({
        title: { text: '消费分布', ... },
        tooltip: { trigger: 'item' },
        legend: { top: '5%', left: 'center' },
        series: [{
            name: '消费价格',
            type: 'pie',           // 饼图
            radius: ['40%', '70%'], // 环形（内半径 40%，外半径 70%）
            data: data              // 动态数据
        }]
    })
}
```

**关键点**：
- `map` 把 `items` 转换成 ECharts 需要的 `{ value, name }` 格式
- `this.chart.setOption()`：更新图表数据，ECharts 会自动重绘
- `radius: ['40%', '70%']`：做成环形图，中间空心

## 五、数据流向总结

```
用户输入 → data (searchName/searchPrice)
    ↓
点击添加 → add() 方法
    ↓
发送 POST 请求 → 服务器返回数据
    ↓
更新 items 数组 → Vue 响应式更新表格
    ↓
调用 updateChart() → ECharts 更新饼图
```

## 六、常见问题

### 1. 为什么图表不显示？
- 检查 `.echarts-box` 有没有设置 `height`
- 检查 ECharts 是否在 `mounted` 中初始化
- 检查数据格式是否正确 `{ value, name }`

### 2. 为什么添加后图表没更新？
- 确保在 `add()` 和 `del()` 中调用了 `this.updateChart()`
- 确保 `chart` 实例已正确保存到 `data` 中

### 3. POST 请求返回 Forbidden？
- `/api/cart` 不支持直接 POST，练习 POST 要用 `/api/post`
- `/api/post` 只是测试接口，不会真的保存到购物车列表

## 七、学习要点

1. **Vue 3 基础**：`data`、`computed`、`methods`、`created`、`mounted`
2. **Axios 请求**：`GET` 带参数、`POST` 带请求体
3. **ECharts 使用**：初始化 → `setOption` → 数据更新时重新 `setOption`
4. **响应式原理**：修改数组后 Vue 会自动更新视图
5. **生命周期**：`created` 发请求，`mounted` 操作 DOM
